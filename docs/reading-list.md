# Local-First Reading List

Local-first software puts the user's data on their own devices first: the app treats the local copy as the source of truth and treats the network as a sync mechanism rather than a prerequisite for doing work. This reading list anchors the current landscape of CRDTs, sync engines, and offline-first apps by collecting the reference projects, the organizations in the space, and a snapshot of live community activity around the leading project, so you can jump from one overview straight to the primary sources.
